ITEM STAT ENGINE
----------------

The classes under com.grimdawn.itemstats, which compute an item's real
seed-applied stats, are derived from:

  Grim Dawn Item Stats                by marius00
      https://github.com/marius00/GrimDawnItemStats
      (published on the web as "Grim Dawn Seed Finder")

The project states that its SDKs "are meant to be integrated into third-party
tools that already parse the game database", that each "is self-contained with
zero dependencies", and that integration is "by project reference or by copying
the source files". It is offered "as-is, as a guide for third-party
implementations. No support or bug reports."

No stat or game data files are taken from it -- only the rolling algorithm.
That project asks for no support requests or bug reports. This one takes bug
reports on its forum thread and nothing else: see the note on support in
README.txt.

The sources are not committed to this repository. scripts/fetch-item-stats.sh
retrieves them at a pinned commit, recorded at the top of that script, and the
build compiles them in.
